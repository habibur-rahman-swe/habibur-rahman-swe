## Research Thesis

### [Osteoporosis Diagnosis Using Knee X-ray Images](https://github.com/habibur-rahman-swe/osteoporosis-diagnosis-X-ray-4-2)

Computer-aided diagnosis (CAD) of **knee osteoporosis** using **CNNs** and **transfer learning**. Knee radiographs are cheaper and more accessible than DXA, yet prior CAD work has focused mainly on hip, spine, hand, and teeth — leaving knee osteoporosis comparatively underexplored.

| | |
|--|--|
| **Problem** | Binary classification: Healthy vs Osteoporosis from knee X-rays |
| **Dataset** | **1,573** images (780 Healthy / 793 Osteoporosis) from 4 public Kaggle datasets |
| **Method** | **Xception** (ImageNet pretrained) + fine-tuning, augmentation, class weights, early stopping |
| **Results** | Test accuracy **93.9%** · macro Precision / Recall / F1 **0.94** |
| **Artifacts** | [Thesis PDF](https://github.com/habibur-rahman-swe/osteoporosis-diagnosis-X-ray-4-2/blob/main/Thesis_Report_4_2.pdf) · [Kaggle notebook](https://www.kaggle.com/code/habib0155/osteoporosis-diagnosis-x-ray) · [Full README](https://github.com/habibur-rahman-swe/osteoporosis-diagnosis-X-ray-4-2) |

**Planned research directions:** multi-stage diagnosis (normal / osteopenia / osteoporosis) · explainable AI (e.g. Grad-CAM) · cross-site generalization · clinical covariates · screening prototypes for low-resource settings
